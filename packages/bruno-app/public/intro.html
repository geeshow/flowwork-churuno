① 실행에서 얻은 CIF가 ②의 입력에 자동으로 채워져 바로 실행됩니다.

Flowwork를 이루는 세 축

개발자의 Bruno, 실무자의 API Chain, 그리고 둘을 잇는 하나의 Git 저장소.

Bruno — API를 만든다

브라우저에서 요청을 만들고 저장하면 .bru 파일로 Git 브랜치에 쌓입니다. 검토를 거쳐 main에 반영된 API가 곧 카탈로그입니다.

API Chain — 흐름으로 엮는다

카탈로그의 API를 스텝으로 쌓아 워크플로우를 만듭니다. 이전 응답·환경변수·사용자 입력이 다음 요청의 변수로 흐릅니다.

Flowwork AI — 골라서 실행한다

자연어 명령에서 키워드·값을 추출해 워크플로우를 매칭하고, 한 번에 못 푸는 일은 징검다리 조합으로 엮어 그 자리에서 실행합니다.
